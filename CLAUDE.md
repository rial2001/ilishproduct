Это статический сайт ilishproduct.ru, раздаётся nginx на сервере ilish.

Файлы редактируй как обычно (диск W:).

Git НЕ запускай на диске W:. Все git-команды выполняй через SSH:

&#x20; ssh web@192.168.0.95 "cd /var/www/website \&\& git <команда>"

Перед крупными правками делай коммит. Конфиги nginx не трогай.
